# Federation preview model migration

The Unity compatibility branch now integrates the offer federation v2 contract from [#4944](https://github.com/beamable/BeamableProduct/pull/4944). The earlier `CampaignOffer*` preview models and `IFederatedCampaignVirtualOffer` interface were removed upstream. Preview consumers must rebuild and migrate to the current contract; this PR does not restore legacy adapters.

## Provider and client models

Provider implementations use `IFederatedVirtualOffer` and the handwritten `Offer*` types in `Beamable.Common`. Follow `cli/beamable.common/Runtime/Federation/FederatedVirtualOffer.cs` for method signatures and field semantics. In particular, `RedeemGrant` receives an `OfferGrantRef` and a separate `Dictionary<string, string>` parameter; there is no `CampaignOfferRedeemRequest` model.

Client responses use generated types in `Beamable.Api.Autogenerated.Models`, including `PlayerOffersPage`, `PlayerOffer`, `OfferItem`, `OfferAmount`, and `OfferGrantState`. These are distinct from similarly named provider models. Their canonical source is `cli/beamable.common/Runtime/OpenApi/Models.gs.cs`.

Message-rail preview consumers must also import `Beamable.Api.Autogenerated.Models.MessageRailRegistrationResponse`, moved from `Beamable.Common` by #4947. `MessageRailRecipient` remains in `Beamable.Common`.

## Optional fields and maps

Generated fields such as `OfferAmount.amount`, `PlayerOffer.available`, and `OfferItem.title` use optional wrappers. Check `HasValue` before reading `Value` when absence matters. `PlayerOffer.state` is a direct enum value. The v1 localization map is no longer part of `OfferItem`; v2 carries display text directly.

With Unity's generated serializer, unset optional fields are omitted from JSON. A present optional string map can carry null, an empty object, or a populated object. Provider dictionaries retain the semantics declared in the handwritten contract. This PR does not change microservice JSON converters.

## Validation boundary

Regression coverage checks the copied federation files and generated dependency closure against canonical source. Unity Editor tests exercise missing, null, empty, and populated string maps, nested responses, display text, false, and zero. These checks do not establish live offer-service or player-build behavior.
