# Federation preview model migration

The Unity Common copy now uses the generated federation models introduced in canonical Common by [#4947](https://github.com/beamable/BeamableProduct/pull/4947). This repairs the mismatch left by the main-branch merge into #4917. It does not introduce the later offer-federation v2 contract.

Preview consumers that compiled against the handwritten models must rebuild against the generated contract. No legacy types or compatibility adapters are provided. The handwritten federation files were absent from the Unity 6.2.0 release tag, but were present in a CLI nightly, so preview consumers may be affected.

## Namespace changes

Import `Beamable.Api.Autogenerated.Models` for these types, previously in `Beamable.Common`:

- `CampaignOffer`, `CampaignOfferAmount`, `CampaignOfferGrantContext`, `CampaignOfferGrantResponse`
- `CampaignOfferItem`, `CampaignOfferReason`, `CampaignOfferRedeemResponse`, `CampaignOfferState`
- `CampaignOfferText`, `CampaignOffersResponse`, `MessageRailRegistrationResponse`

Federation interfaces and request types such as `CampaignOfferGrantItem`, `CampaignOfferRedeemRequest`, and `MessageRailRecipient` remain in `Beamable.Common`. Update fully qualified names and response signatures accordingly.

## Optional fields and maps

Follow the declarations in `cli/beamable.common/Runtime/OpenApi/Models.gs.cs`, the canonical generated source. Fields such as `CampaignOfferAmount.amount`, response `success`, and offer `available` now use optional wrappers. Check `HasValue` before reading `Value` when absence matters; an absent value is different from an explicit zero or false.

`properties` and `extraDataFed` use `OptionalMapOfString`. `CampaignOfferItem.localizations` uses `OptionalMapOfCampaignOfferText`, containing a `MapOfCampaignOfferText`. Replace assignments of raw dictionaries with the generated map and optional types. Required fields, including `CampaignOfferText.title`, remain direct values; do not apply `.Value` indiscriminately.

With Unity's generated serializer, unset optional fields are omitted from JSON. A present optional map can carry null, an empty object, or a populated object. Localizations remain a JSON object keyed by locale, with title/description objects as values. `CampaignOfferRedeemRequest.params` and `MessageRailRecipient.data` retain their existing dictionary contracts.

Unity uses the generated serializer. This PR does not change microservice JSON converters or repair upstream model serialization in the microservice transport. Those concerns remain with the upstream model owners.

## Validation boundary

Regression coverage checks the copied federation files and the complete generated dependency closure against canonical source. Unity Editor tests exercise generated serialization for missing, null, empty, and populated string maps, nested responses, localizations, false, and zero. These checks do not establish live campaign-service or player-build behavior.
